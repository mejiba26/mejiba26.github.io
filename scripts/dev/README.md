# scripts/dev

Test helpers for the paper trading card and the volatility scorecard. Not part of the site; nothing here runs in a workflow.

- `make_paper_sample.py` writes fake `data/paper/` style files and a copy of `index.html` with a fixed clock (`?s=<scenario>&now=<date>`). Run it, then `cd` into the folder it prints and `python -m http.server 8765`. Every file is labeled SAMPLE DATA, NOT A TRACK RECORD (JSON files carry a `_sample` key; `ledger.csv` cannot, because the page checks its header exactly, so it sits in a folder and beside a marker file that carry the label). It defaults to the system temp folder and refuses to write inside `data/paper/`.
- `check_no_sample_staged.sh` exits 1 if a staged path looks like sample data. Run it before committing.
- `test_paper_trade.py` is an offline test of the simulator (synthetic prices, no network): `python scripts/dev/test_paper_trade.py`. It checks that a rerun on the same day changes nothing and that a run split across several days equals one continuous run. It uses a temp folder and never touches `data/paper/`.
- `test_update_vol.py` is the offline test of the volatility scorecard (synthetic prices, no network): `python scripts/dev/test_update_vol.py`. It checks that a rerun changes nothing, that a run split across days equals one continuous run, that no forecast uses later data, that the 80% intervals cover about 80% on data with a known distribution, that a second independent EWMA and HAR match the script, the late rule, the Friday first forecast rule, the holiday calendar, loud failures, scoring and the schema check. `python scripts/dev/test_update_vol.py --mutants` breaks the script on purpose, one thing at a time, and confirms the tests notice each break (about four minutes).
- `make_vol_sample.py` runs the real `scripts/update_vol.py` on synthetic prices with a fake clock and writes `data/vol/` style files plus a copy of `index.html` with a fixed clock (`?vs=<scenario>&now=<date>`). Run it, then `cd` into the folder it prints and `python -m http.server 8766`. Everything is labeled SAMPLE DATA, NOT A TRACK RECORD. It defaults to the system temp folder and refuses to write inside `data/vol/`.
